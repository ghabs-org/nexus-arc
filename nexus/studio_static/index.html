YOUR WORKSPACE

Workspace tools

Manage memory, resume work, coordinate specialists, and review execution.

Conversation memory

Your Studio conversations. Archive and restore without deleting history. Legacy bot histories stay in their configured ARC stores.

Import conversation history

Imported messages become your own conversation. Existing history is retained and repeated imports are detected.

Mapped legacy sources

An administrator must map your Nexus identity to your legacy bot user ID before Studio can read older stores.

Workflow checkpoints

Durable SQLite snapshots of canvas workflows. Resume current unfinished steps after a failure or approve a pending gate. Completed steps are retained.

Agent coordination

Delegate to saved specialists in sequence or parallel. Each uses its configured provider. Presence shows local invocations or an explicitly connected peer registry.

Manage external A2A agents →

Recent peer presence

Publishing campaigns

Draft per-channel copy, check content and required account fields, then approve a specific revision. Validation does not verify live account authorization. Publishing requires a separate reviewed confirmation and never retries uncertain results automatically.

Audit analytics

Execution metadata from ARC's audit query interface. Prompts and output content are excluded. Counts cover runs with events in the chosen window.

Audio transcription

Upload up to 4 MiB. Whisper uses your configured OpenAI API key and API billing; coding-agent subscription sign-in is not used. Uploaded audio is removed after processing.

Typed decisions

Request a named choice from Jev, inspect reported confidence, and use an explicit fallback below your threshold. Launching a matching saved agent remains a separate action.

File storage

Choose where new artifact bytes are stored. Existing versions retain their original backend. Cloud credentials belong to the service; files use separate user namespaces. Shared changes require the owner role.

S3 options: region, endpoint_url, access_key and secret_key. GCS: project. Azure: connection_string. Credential values must be objects such as {"env":"STORAGE_SECRET"}. Local storage needs no options.

Prompt and launch controls

Personal execution settings. Budgets use characters, preserve the current task/instructions, and compact older conversation history. These controls do not measure tokens, money or subscription quota.
